# Nexa

Réseau social moderne — profils, groupes, messagerie privée et publications.

## Fonctionnalités

- **Profils** : Avatar, bio, statistiques personnalisables
- **Groupes** : Publics et privés, chat de groupe en temps réel
- **Messages privés** : DM entre utilisateurs, temps réel
- **Publications** : Fil d'actualité, réactions, commentaires
- **Recherche** : Trouver des utilisateurs et des groupes
- **Notifications** : Nouveaux messages, likes, mentions

## Stack technique

- **Backend** : Python (Flask + Flask-SocketIO)
- **Base de données** : SQLite
- **Frontend** : HTML5 + CSS3 + JavaScript vanilla
- **Temps réel** : WebSocket (SocketIO)
